# Anime Viewer 배포

Anime Viewer Windows 설치 파일을 받는 곳입니다. 설치한 앱은 이 저장소의 최신 릴리스를 확인해 스스로 업데이트합니다.

## 설치

1. [최신 릴리스](https://github.com/Supermale/anime-viewer-releases/releases/latest)에서 `AnimeViewer_<버전>_x64-setup.exe`를 받아 실행합니다.
2. Windows가 “Windows의 PC 보호” 또는 “알 수 없는 게시자” 경고를 띄우면 **추가 정보 → 실행**을 누릅니다. 코드 서명 인증서를 쓰지 않아 처음 설치할 때 나타나는 경고입니다.
3. Chrome 또는 Edge와 WebView2가 필요합니다. Windows 10/11에는 보통 이미 설치되어 있습니다.

## 업데이트

앱을 켜면 새 버전을 확인합니다. 새 버전이 있으면 화면 오른쪽 위에 **업데이트** 배지가 나타나고, **앱 정보**에서 변경 내용을 보고 **지금 업데이트**를 누르면 설치 후 앱이 다시 열립니다. 찜·시청 기록·자막 설정은 그대로 유지됩니다.

## 포함 소프트웨어

설치 파일에는 Node.js, Playwright, mpv가 포함됩니다. 라이선스와 소스 위치는 설치 폴더의 `bundled-runtime\THIRD-PARTY.txt`에 있습니다.
